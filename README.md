# Portafolio personal · Stiven Builes

Portafolio web estático y adaptable a móviles, creado con HTML semántico y utilidades de Tailwind CSS.

## Abrir el proyecto

Abre `index.html` en un navegador o inicia un servidor local desde la carpeta del proyecto:

```bash
python3 -m http.server 8000
```

Después visita <http://localhost:8000>. Tailwind CSS se carga desde su CDN, por lo que se requiere conexión a internet para aplicar los estilos.

## Publicación

El repositorio es público y GitHub Pages está configurado para publicar la carpeta raíz de `main`. Tras subir los cambios a esa rama, el sitio estará disponible en:
